# 采购公告实体挖掘与关系分析平台

## 导入与启动

1. 将本 ZIP 导入 Replit 项目根目录，保留 backend、frontend、seed、gold 文件夹。
2. 添加 PostgreSQL 数据库，确认项目 Secrets 中存在 DATABASE_URL。
3. 点击 Run。入口自动安装 requirements.txt 中的依赖并运行 cloud_server.py。
4. 打开预览，选择“官方数据集全量提取（1038篇）”，可浏览结果、关系分析、画像并下载标准 XLSX。
5. 在 Replit 发布页面选择账户可用的免费发布选项；若提示收费，请先核对账户方案。

## 内置内容

包含1038篇公告记录、8012条标的明细、2870条模型缓存及1038份核验答案。
其中两篇大型附件保留空值占位。前端已构建，部署时无需再次安装 Node.js 或构建前端。
完整数量与校验值见 seed/manifest.json。

## 新增处理

访客在“模型配置”填写自己的 API Key，随后在“数据集导入”上传公告与附件并开始处理。
默认模型 deepseek-flash。当前标签页保存个人配置，后台任务绑定发起者的配置。
已有记录的浏览和下载不调用模型。新任务运行会消耗访客所配置 Key 的额度。
任务范围可选单个任务或全部任务，关系分析及画像随所选范围生成。
单任务清除保留已入库结果、模型缓存和数据集完成状态。

## 数据保存

服务监听0.0.0.0，端口使用 PORT，默认3000。
首次启动从 seed 初始化数据库，后续使用 PostgreSQL 已有数据，避免重复覆盖。
新增结果、任务和上传文件保存到 PostgreSQL。未配置 DATABASE_URL 时使用本地 SQLite，适合本地预览。
原有官方大附件未随包复制；历史结果、公告正文与模型缓存已包含，新增处理请上传对应原始文件。
包内不含本机 .env、私人 API Key、node_modules 或临时运行数据库。
